# SmartERP Project Brief

> This is the permanent spec file. Re-read it at the start of every new phase.

SmartERP is a cloud-based, Tally-inspired Billing, Inventory, and Accounting Management System.

**Tech Stack:**
- Frontend: Next.js (App Router), React, Tailwind CSS, ShadCN UI, TanStack Table, React Hook Form + Zod
- Backend: Node.js + Express.js (REST API)
- Database: PostgreSQL (local for dev)
- Auth: JWT-based
- PDF: PDFKit
- Excel Export: ExcelJS
